# Research with Parallel Search MCP in Colab

Use [Parallel Search MCP](https://docs.parallel.ai/integrations/mcp/search-mcp)
to gather web excerpts and source URLs for a report. Anonymous search uses Fast
mode and is free for light use, with no account or API key. The service has usage
limits. This optional, manual workflow leaves the notebook's DuckDuckGo and
Wikipedia agent unchanged.

## Gather web context

Run this cell once per research session. It uses MCP's Streamable HTTP transport
and keeps the same session identifier for related searches. No Parallel
credentials are read from notebook secrets or environment variables.

```python
import asyncio
import json
import uuid

import httpx
from mcp import ClientSession
from mcp.client.streamable_http import streamable_http_client

research_session_id = uuid.uuid4().hex


async def parallel_context(topic, search_queries):
    async with asyncio.timeout(60):
        async with httpx.AsyncClient(
            headers={"User-Agent": "autonomous-research-and-report-gen-agent/parallel-guide"},
            timeout=30,
        ) as client:
            async with streamable_http_client(
                "https://search.parallel.ai/mcp", http_client=client
            ) as (read, write, _):
                async with ClientSession(read, write) as session:
                    await session.initialize()
                    result = await session.call_tool(
                        "web_search",
                        {
                            "objective": f"Find reliable sources for a report about {topic}",
                            "search_queries": search_queries,
                            "session_id": research_session_id,
                        },
                    )

    text = "\n".join(block.text for block in result.content if block.type == "text")
    if result.isError:
        raise RuntimeError(f"Parallel search failed: {text}")
    payload = result.structuredContent or json.loads(text)
    sources = payload.get("results", [])
    chunks = [
        f"{source.get('title', '')}\n{source['url']}\n"
        + "\n".join(source.get("excerpts") or [])
        for source in sources
        if source.get("excerpts")
    ]
    if not chunks:
        raise ValueError("No web excerpts returned; refine the topic before generating a report.")
    return "\n\n".join(chunks)
```

In another cell, choose a topic and a few short, related queries. Colab supports
top-level `await`; do not wrap this call in `asyncio.run()`.

```python
topic = "Recent progress in renewable energy storage"
web_context = await parallel_context(
    topic,
    ["renewable energy storage recent progress", "grid battery storage research advances"],
)
print(web_context)
```

Review the excerpts and open their source URLs before generating the report. If
the request fails, times out, or reaches a usage limit, stop and retry later as
directed by the service. Keep the session identifier when retrying related
searches. No report is generated by the search cells.

## Generate and save a report

After reviewing the retrieved context, run:

```python
context = clean_and_combine(topic, web_context, "")
report = create_cover_page(topic) + generate_detailed_report(topic, context, llm)
print(report)
save_report(topic, report)
```

This calls the existing report functions directly, using Parallel excerpts as
the web context. It does not run the ReAct agent or fetch Wikipedia context.
The notebook currently limits combined context to 1,500 characters and uses only
the first 600 characters in each generation prompt, so focus the topic and review
which excerpts fit. Phi-2 can still make mistakes, and the report generator removes
numeric citation markers. Keep the printed source URLs for fact-checking; the
saved report is not a cited research paper.
